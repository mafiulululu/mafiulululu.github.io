Pet Adoption Center

Pet Adoption Center is a web-based platform designed to simplify the pet-adoption process. Users can explore available pets by category, create an account, submit adoption applications and manage their adoption requests through the system.

The platform also includes pet-care shopping features, allowing users to browse pet food, toys, homes and healthcare products, add products to a cart and continue through a checkout workflow.

Key Features

  • User registration, login, logout and session-based access
  • Separate pet categories for cats, dogs, rabbits and tortoises
  • Pet-adoption application submission
  • Adoption-request viewing and cancellation
  • Pet food, toys, homes and healthcare product sections
  • Shopping-cart and checkout functionality
  • Administrative dashboard for managing pet information
  • Administrator options for adding and deleting pets

Software Quality Focus

The project provides practical opportunities for authentication testing, form-validation testing, functional testing, role-based access testing, database verification, responsive testing and complete adoption-workflow testing.

Technical Highlights

The application uses PHP for server-side functionality, MySQL for data management and HTML, CSS and JavaScript for its user interface. Its folders are organised into separate user and administrator areas with an MVC-style structure.

ASP.NET Core MVC Healthcare Application

SmartClinic

SmartClinic is a clinic-management web application developed using ASP.NET Core MVC. It is designed to organise essential clinic operations through separate areas for administrators, doctors and patients.

The system includes modules for managing doctors and patients, scheduling appointments, generating invoices, delivering notifications and displaying dedicated dashboards for different types of users.

Key Features

  • User account and authentication functionality
  • Separate administrator, doctor and patient dashboards
  • Doctor information management
  • Patient information management
  • Appointment booking and appointment management
  • Invoice creation and invoice-management functionality
  • PDF invoice service
  • System notification management
  • Structured healthcare data storage using SQL Server

Software Quality Focus

This project provides practical opportunities for authentication testing, dashboard-access testing, appointment-workflow testing, form-validation testing, database testing, invoice verification, notification testing and responsive user-interface testing.

Architecture and Technical Highlights

SmartClinic follows a layered software architecture. The application layer handles controllers, views and view models, the business-logic layer contains services and data-transfer objects, and the data-access layer manages Entity Framework and repository operations.

This structure separates the user interface, business rules and database operations, making the system easier to maintain, test and extend.
